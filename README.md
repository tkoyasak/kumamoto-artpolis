# kumamoto-artpolis

A static site cataloging the buildings and structures of the [Kumamoto
Artpolis](https://www.pref.kumamoto.jp/soshiki/115/85889.html) architecture
program, paired with a log of visits to them.

The home page pairs a table of catalog entries with a fullscreen map; hovering
a row highlights its marker and vice versa. Each entry has its own prerendered
detail page, and a separate timeline records site visits.

## Stack

- Astro (SSG)
- Preact table island + MapLibre GL map island
- Tailwind CSS
- Cloudflare Workers static assets
